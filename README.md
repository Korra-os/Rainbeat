# Rainbeat

A simple rhythm game made for those who like to relax and play games with music.

## The Problem

I have always enjoyed playing rhythm games and have wanted to make one myself, but before coming to Purdue, I didn't have the knowledge or experience in coding required to do so. 
This project serves to test my current knowledge and what I have learned in order to create a rhythm game for users to play and enjoy.

## How It Works

During the MVP process of this project, users will be able to start a map from the main menu and press four keys, corresponding with four lanes, in timing with notes from each lane once the notes reach the bottom of the screen.

Once completed, a user will be able to select any given song and press play to begin the map. When a song is selected and started, the user will be able to press four keys, corresponding with four lanes on screen, and time their key presses with the notes once each note hits the bottom of the screen. The user will continue to press keys corresponding with the notes until the song has ended, or the user chooses to quit playing the song. Once a song is completed, the user will be able to view a screen of their statistics over the song they played. After exiting this screen, the user will then be able to choose another song to play or be able to exit the game.

## Roadmap

- [ ] Music synchronization with charts
- [ ] Pause, restart, and exit ability while playing a map
- [ ] Tracking statistics such as score, accuracy, keys per second, and health
- [ ] Settings menu to configure key bindings and optimizations for gameplay
- [ ] Interactive song menu for users to select from a list of songs to play a map from.
